# 💼 Portfólio Pessoal - Leonardo Pinheiro

> Portfólio profissional desenvolvido com HTML5 semântico, CSS3 moderno e JavaScript Vanilla, com foco em alta performance, responsividade e experiência do usuário (UX).

---

## 🎯 Objetivo do Projeto

O objetivo principal deste projeto é centralizar e apresentar a trajetória profissional, competências técnicas e os principais projetos desenvolvidos por **Leonardo Pinheiro**, atuando como Desenvolvedor Full-Stack.

A aplicação foi planejada para fornecer uma experiência de navegação rápida, fluida e intuitiva tanto para recrutadores quanto para clientes e desenvolvedores da comunidade, destacando soluções reais desenvolvidas com tecnologias modernas do ecossistema JavaScript/TypeScript, bancos de dados relacionais e inteligência artificial.

---

## 🧭 Visão Geral

O portfólio funciona como uma Single Page Application (SPA) estática, priorizando código limpo, sem dependência de bibliotecas externas pesadas e com suporte nativo a temas e acessibilidade.

### ✨ Principais Funcionalidades

- **👤 Perfil & Apresentação**: Resumo profissional com foto, descrição de foco de atuação e links diretos para redes sociais (LinkedIn, GitHub, Instagram e E-mail).
- **🧠 Seção de Habilidades (Skills)**: Exibição visual com badges das principais ferramentas e linguagens dominadas (HTML, CSS, JavaScript, React, Node.js, Docker, PostgreSQL).
- **🎓 Formação Acadêmica & Cursos**: Histórico acadêmico e certificações complementares, incluindo graduação em Análise e Desenvolvimento de Sistemas, proficiência em Inglês e certificações técnicas.
- **🚀 Vitrine de Projetos (Showcase)**: Apresentação detalhada dos principais projetos full-stack em produção, contendo descrição, tecnologias empregadas, capturas de tela e links diretos para as aplicações:
  - **BEWEAR**: E-commerce moderno de moda e vestuário construído com Next.js, TypeScript, Drizzle ORM, PostgreSQL, Better Auth e Stripe Checkout.
  - **FIT.AI**: Plataforma de gerenciamento de treinos com geração de rotinas personalizadas via assistente conversacional de IA.
  - **Aparatus**: SaaS de agendamento em barbearias em tempo real com assistente inteligente (Agenda.ai) integrada.
  - **Fintrack**: Dashboard financeira para gestão e rastreamento de receitas/despesas desenvolvida com React + Vite e Tailwind CSS.
- **🌓 Alternância de Tema (Dark/Light Mode)**: Suporte dinâmico a modo escuro e claro com persistência automática da preferência do usuário via `localStorage`.
- **🧭 Navegação Fluida**: Menu fixo com *smooth scrolling* que calcula a compensação de altura do cabeçalho.
- **📱 Design 100% Responsivo**: Layout flexível e adaptável para qualquer resolução de tela (smartphones, tablets e monitores desktop).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Estilização moderna, variáveis CSS (*custom properties*), Flexbox, CSS Grid e Media Queries para responsividade.
- **JavaScript (ES6+)**: Manipulação eficiente do DOM, lógica de alternância de tema e cálculo de rolagem suave.
- **Font Awesome**: Ícones vetoriais para interface, navegação e redes sociais.

## 🚀 Como Executar o Projeto Localmente

Como o projeto é construído exclusivamente com tecnologias web nativas, nenhuma etapa de compilação ou instalação de dependências é necessária.

### 1. Clonar o repositório
```bash
git clone https://github.com/leopinheirosilva/portfolio.git
cd portfolio
```

### 2. Abrir o projeto
Você pode abrir o projeto diretamente no navegador de três formas:

- **Diretamente no navegador**:
  Dê dois cliques no arquivo `index.html` ou abra-o diretamente no navegador de sua preferência.

- **Com a extensão Live Server (VS Code)**:
  Abra a pasta do projeto no VS Code, clique com o botão direito em `index.html` e selecione **"Open with Live Server"**.
